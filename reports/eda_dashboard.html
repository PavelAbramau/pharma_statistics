1. Is months_since_last_version bimodal?

Real, if imperfect, bimodal structure — BIC prefers two components, though Ashman's D (1.68) shows the two clusters still overlap substantially.

N=2847 trials with a resolvable last-version date. This determines whether a fixed staleness cutoff is even meaningful, or whether the labelling task has to treat every case on a continuum.

2. Event-type frequency

Dates pushed later (9056 pairs, blue) outnumber dates pulled earlier (2303 pairs, red) by 3.9x.

Slippage is near-universal registry hygiene; a pulled-earlier date is rare and, per this project's hypothesis, the sharper signal.

3. Feature correlation + PCA

No single component dominates (PC1 = 38%) — the features carry meaningfully distinct information.

Condition number is astronomical because staleness_age_adjusted is an exact linear combination of staleness and months_since_start (both also in this matrix) — mechanical, not a data surprise.

N=1002 programs (silence_score excluded — deterministic function of 3 of the other features, would double-count them).

4. Survival, by phase — two different questions

Two different questions, kept separate: panel A's event (reaching a terminal registry status) is confounded by status-update lag; panel B's event (no new version posted in >180 days) is status-independent — the base rate this project actually needs.

1818 trials are amendment-silent (panel B) vs 1441 formally terminal (panel A) — 377 more (26%) look quiet on the amendment record without the registry status catching up yet. n=2709 trials.

5. Sponsor clustering

Sponsor names withheld — distributions and rank only. Intra-sponsor ICC of staleness: 0.18 (F(92,864) one-way ANOVA).

Substantial — programs from the same sponsor are NOT independent observations. A sponsor running out of money plausibly takes multiple programs stale at once.

6. Regional strata

Proxy: every trial location on file for the program is in China (not a direct sponsor-nationality field). Effect size d = standardised mean difference.

Significant (p<0.05) on: staleness, status_ambiguity, verification_lapse, amendment_count, months_since_start, has_results. Any feature differing systematically by region should get a separate base rate, not a pooled one.
